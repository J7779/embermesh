# Allow-list for tools/check-publishable.sh
#
# One entry per line:   <rule> <kind> <value>        # why it is allowed (required by convention)
#   rule   a rule name printed by the checker (email, uuid, mac, ip, callsign, coord, credential,
#          home-path, temp-path, residue, imei, filename, binary, large, image-meta), or * for all
#   kind   path   <glob>  the rule does not apply to files matching this shell glob (* crosses /)
#          match  <ERE>   a finding whose matched text matches this extended regex is accepted
#                         (case-insensitive; anchor it with ^...$ to accept one exact value;
#                         no {n} intervals: they are evaluated by awk, which may not support them)
#          term   <literal>  (content rules) a finding is accepted when every occurrence of the
#                         matched word on that line lies inside this literal, compared
#                         case-sensitively; the same word anywhere else on the line still fails.
#                         For names a tool convention imposes, never for prose
#          file   <path>     (filename rule only) this exact file, at the repository root, may be
#                         published although its parent directory is refused; same rules as dir
#          dir    <prefix>   (filename rule only) this one directory, at the repository root, may be
#                         published although its name is refused elsewhere; every other filename
#                         pattern (keys, keystores, logs, OS/editor/build residue) still applies to
#                         the files inside it, and all content rules apply as everywhere else
# The value ends at the first space; everything after " #" is the comment. Adding a legitimate
# third-party e-mail address is one line:   email match ^someone@project\.org$   # vendored X author
# Never list the machine identifiers here (user, host, e-mail, tokens): those are discovered at
# run time and cannot be allow-listed. The one exception is the owner-approved public identity:
#   identity path <glob>  in these files a copyright statement ("Copyright (c) <years> <name>",
#                         "© <year> <name>") may carry the git user.name (display name only; never
#                         the e-mail, its local part, a GitHub handle, the OS user, host or paths)
#                         when the line holds no other identifier of this machine.

# --- Owner-approved public identity (copyright lines only) --------------------------------------------
identity path LICENSE                                       # owner-approved copyright line (MIT)
identity path README.md                                     # owner-approved copyright line (licence section)
identity path THIRD_PARTY_LICENSES.md                       # owner-approved copyright line
identity path CONTRIBUTING.md                               # owner-approved copyright line
identity path ui/js/lib/about.js                            # owner-approved copyright line (UI About text, APP_LICENCE)
