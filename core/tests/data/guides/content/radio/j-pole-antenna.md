# Building a J-Pole Antenna for 2 m

A J-pole is an end-fed half-wave antenna with a quarter-wave matching stub. For 146.52 MHz
the long element is about 145 cm and the short stub about 48 cm. Feed it with 50 ohm coax
at the point of lowest SWR, found by sliding the tap up the stub.
