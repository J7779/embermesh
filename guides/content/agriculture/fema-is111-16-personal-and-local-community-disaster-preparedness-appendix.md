### Safety Inspection Checklist

The following form is used by some insurance companies to identify potential hazards on farms. Review each item to identify potential hazards on your farm.

| ELECTRICAL SYSTEM | YES | NO |
|---|---|---|
| 1. Each building’s Service Entrance Equipment is located in dry, dust-free location. | | |
| 2. Service Entrance Equipment is mounted on fire resistive material. | | |
| 3. Service Entrance Equipment is free of rust and other signs of deterioration. | | |
| 4. Electrical fixtures are properly covered so they do not fill with cobwebs, dirt, chaff. | | |
| 5. Circuits are properly fused with correct size fuses. | | |
| 6. All wiring is in good condition with no signs of fraying or deterioration. | | |
| 7. All lighting fixtures are properly protected. | | |
| HEATING UNITS | YES | NO |
| 1. Are heating units designed for use in barns and stables? | | |
| 2. Are heating units properly insulated from combustible material? | | |
| 3. Are heating units serviced at least annually by a competent heating contractor? | | |
| 4. Is the use of portable heating units prohibited? | | |
| ABOVE-GROUND FUEL STORAGE | YES | NO |
| 1. Are tanks located at least 40 feet from any building? | | |
| 2. Are tanks properly grounded? | | |
| 3. Is a 5-pound or larger class ABC Fire Extinguisher conveniently located near tank? | | |
| 4. Is tank properly protected from collision by vehicular traffic? | | |
